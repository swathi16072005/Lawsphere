# **App Name**: LawSphere

## Core Features:

- Justice Navigator (AI Legal Assistant): Users describe legal problems in natural language, and the AI tool uses simulated RAG to generate an 'Legal Action Plan' with relevant Indian Law sections, precedent judgments, and clear 'Why this matters' explainers.
- Contract Shield (AI Document Analysis): Enables users to upload contracts (PDF/Text) for automated analysis. The AI tool extracts clauses, assesses risk by highlighting 'Unfair Terms' in red and 'Standard Terms' in green, and provides a comparison against typical clauses.
- Proof Pro (AI Evidence & Probability): Presents a visual 'Case Strength' meter based on user input or uploaded documents. The AI tool dynamically generates a personalized checklist of 'Suggested Proofs' required to strengthen their legal standing.
- Lawyer Connect (Legal Aid Finder): Provides a directory or search interface for users to find legal aid professionals and services relevant to their specific case category and needs.
- Agentic Simulation Feedback: Incorporates mock 'Thinking...' steps (e.g., 'Searching IPC Sections...', 'Analyzing Precedents...', 'Calculating Risk...') to visually represent the AI's processing and provide transparent user feedback.
- Responsive Mobile-First UI: A fully responsive, mobile-first user interface with smooth transitions and modern glassmorphism cards for an intuitive and engaging user experience, designed with Tailwind CSS.

## Style Guidelines:

- A professional and trustworthy 'Justice & Modernity' palette is used. The primary color is a deep navy (#1A2A6C), providing a strong and authoritative presence.
- The background color is a very light, desaturated blue-grey (#ECF1F3), visually derived from the primary navy hue, evoking a subtle 'Marble White' aesthetic and providing excellent contrast.
- An accent color of vibrant gold (#F1C40F) is used to highlight calls to action, important information, and risk indicators, adding a premium touch.
- Headlines use 'Space Grotesk' (sans-serif) for a modern, tech-forward, and assertive look. Body text utilizes 'Inter' (sans-serif) for its neutrality, excellent readability, and objective feel.
- Lucide-React is employed for crisp, modern UI icons. High-quality SVG illustrations representing legal concepts like Gavel, Scales of Justice, Constitution of India, and High Court buildings are used for thematic visuals.
- The layout is mobile-first and fully responsive, leveraging Tailwind CSS for efficient styling. Key elements include glassmorphism cards for content display, a prominent hero section with a legal-themed background, a clear 'Get Started' CTA, and a dedicated 'Legal Disclaimer' footer.
- Smooth transitions across the application enhance user flow. Framer Motion is used for dynamic entrance animations of elements and result card reveals, providing a polished and engaging interactive experience. AI processing steps feature subtle animated 'thinking' indicators.
